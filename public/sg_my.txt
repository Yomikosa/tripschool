# SG & MY 修学旅行ナビ 開発・トラブルシューティング引継ぎ書

## 1. プロジェクト概要
- **アプリケーション種類**: シンガポール＆マレーシア修学旅行支援PWA（6日間対応: Day 1 〜 Day 6）
- **開発プラットフォーム**: Cloudflare Workers / Pages (Static Assets + Workersフルスタックモード)
- **主要機能**: 
  - リアルタイム＆デモ時間連動スケジュール管理
  - 双方向通貨換算電卓、班別割り勘、指差し会話、国境越えチェックリスト等
  - クイックタイルの長押し編集＆ドラッグ並び替え
  - **Cloudflare KV ＋ パスワードハッシュ（SHA-256）照合によるクラウド同期システム**

---

## 2. これまで実装・達成したこと
1. **フロントエンドの改善とバグ修正**:
   - スケジュールタブの日付変更がアプリ全体の現在日（ホーム画面等）まで変えてしまう問題を修正（現在日 `activeTripDay` と閲覧日 `viewingScheduleDay` を完全分離）。
   - タッチ操作と SortableJS の干渉によるツール誤作動バグ、およびインポートツールを開くと画面が真っ白になるバグを解消。
   - ホテル提示カード機能を廃止し、タイルやツールのカタログを整理。
   - 深夜・日またぎの予定（例: 23:00 - 06:00）に対応した進捗バー＆残り時間計算ロジックの実装。
   - 新規予定追加時に、前の予定の終了時刻を自動継承して時刻セットする仕様の適用。
   - モーダル表示中の背面スクロールロック（iOS Safari対策）の導入。
   - PWA対応（`manifest.json`、`sw.js`）およびUIテーマ（5パターン）変更時の最上部ステータスバー色連動。
   - ヘッダー左上にシンガポールとマレーシアの国旗を取り入れたオリジナルアイコンSVGを配置。

2. **クラウド同期システムの設計**:
   - クライアント側（`index.html`）の `uploadToCloud` / `downloadFromCloud` 関数による `/api/sync` エンドポイントへのPOST/GET通信。
   - バックエンド（`worker.js`）での Web Crypto API (SHA-256) によるパスワードハッシュ照合と Cloudflare KV (`TRIP_KV`) への保存・取得処理。

## 3. 現在直面している課題と試していること
- **発生しているエラー**:
  - クライアントから `/api/sync` にPOSTリクエストを送った際、Cloudflare Workers側で `404 Not Found` が返ってくる。
- **これまでの試行錯誤**:
  - 最初は Cloudflare Pages（Static Assets）として構築したが、「Bindings cannot be added to a Worker that only has static assets」エラーに遭遇。
  - プロジェクトを単体の **Cloudflare Workers** として作り直し、KVバインディング（`TRIP_KV`）の追加には成功。
  - `wrangler.toml` に `[assets]` 設定を記述し、`worker.js` 内で `url.pathname === "/api/sync"` のルーティングと `return env.ASSETS.fetch(request);` による静的ファイルフォールバックを実装。
  - デプロイは `🔵 Ready` になるものの、実際の通信テストで `404 Not Found` が発生し、バックエンドのWorkerスクリプトにリクエストが正しくルーティングされていないか、静的アセットとの結合部分に不整合が起きている状態の切り分けを行っているところ。

---

## 4. 現在のファイル構成
- `index.html`: アプリ本体（UI、ストレージ、UIロジック、クラウド同期クライアント）
- `worker.js`: Cloudflare Workers バックエンドAPI（`/api/sync` のパス分岐、KV操作）
- `wrangler.toml`: Cloudflare設定（`name = "tripschool"`, `main = "worker.js"`, `[assets]`, `[[kv_namespaces]]`）
- `manifest.json`: PWAマニフェスト
- `sw.js`: Service Worker（キャッシュ管理）
